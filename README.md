# rwanda_property_hub
Rwanda Property Hub is a comprehensive online real estate platform designed to connect property seekers (buyers, renters, and investors) with verified agents and landlords. It offers advanced search and filtering, detailed property listings with image galleries, user dashboards, direct messaging, reviews, and rental payment tracking. The platform supports multiple user roles (admin, agent, landlord, buyer, tenant) and includes features like favorites, ad management, and subscription-based ad posting. Built with PHP and MySQL, it provides a secure, responsive, and user-friendly experience for the Rwandan property market.
